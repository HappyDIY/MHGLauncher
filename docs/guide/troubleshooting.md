# 故障排查

先保留现场，再逐层确认问题发生在哪个阶段。不要从删除数据库、清空 Keychain 或重装游戏开始。

## 构建失败

### Xcode 或 SDK 不匹配

确认使用 Xcode 26 和 macOS 26 SDK，并且目标 Mac 为 Apple 芯片。Swift 包只声明 macOS 26 和 arm64。

### 缺少签名证书

当前发布构建要求项目统一证书及私钥。以下情况都会终止构建：

- Keychain 中找不到指定身份。
- 证书名称或 SHA 指纹不匹配。
- App 深度签名校验失败。

CI 使用的临时签名开关不属于普通发布流程，不应作为本地发行方案。

## App 启动失败

本地后端必须由 App 作为子进程启动。如果页面长期停留在准备阶段：

1. 确认 App 包内的 Backend 资源完整。
2. 检查系统是否阻止执行未公证的开发预览 App。
3. 正常退出所有残留的 MHGLauncher 与后端进程后再试。
4. 不要手动启动 `server.js` 或创建 TCP 端口。

## 登录或资料刷新失败

- 检查网络和系统时间。
- 确认当前会话未过期。
- 扫码登录时在移动端完成确认。
- 手机验证码失败时不要连续高频重试。
- 切换角色后确认页面 UID 已更新。

刷新失败但旧数据仍可用时，应用可能保留最近成功内容。根据更新时间判断，而不是立即清空账号。

## 下载停滞

确认磁盘空间、目录权限和网络连接。任务支持暂停或恢复时优先使用页面控制，不要手动删除暂存目录。

若同一位置反复失败，记录任务阶段、资源名称和非敏感错误码。不要提交下载 URL 中可能携带的临时参数。

## 游戏无法启动

按顺序检查：

1. 游戏更新和校验任务已经完成。
2. Wine、DXMT 与兼容资源状态正常。
3. 性能模式恢复到默认或此前可用值。
4. 没有其他游戏进程占用目录。
5. `mhypbase.dll` 已由启动器恢复到固定版本。

如果游戏进程曾被强制结束，等待启动器完成文件和环境恢复后再启动。

## 云端或后台异常

自建环境可以检查：

```bash
curl --fail http://127.0.0.1:3333/health
curl --fail http://127.0.0.1:3400/health
```

返回 `503` 通常表示服务无法完成数据库健康检查。继续查看[自托管云服务](../operations/self-hosting)中的数据库、密钥和容器检查步骤。

## 提交问题前

可提供：

- macOS、Xcode 和项目提交版本。
- 出错页面、任务阶段和操作顺序。
- 已脱敏的错误码与调用时间。
- 是否使用 fixture、live Provider 或自建云端。

不可提供：

- Cookie、验证码、Bearer Token、服务令牌。
- 完整 UID、手机号、邮箱或恢复码。
- 含敏感查询参数的 URL。
