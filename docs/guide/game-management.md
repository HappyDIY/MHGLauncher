# 游戏管理

“游戏”页面负责定位、安装、更新、预下载、校验、修复和启动《原神》国服。耗时操作由后端任务执行，前端持续显示阶段、进度和可用控制项。

## 定位已有游戏

选择已有游戏目录后，启动器会读取本地版本和资源信息，并与当前可用构建进行比较。

定位前建议确认：

- 目录确实属于《原神》国服客户端。
- 当前用户对目录具有读写权限。
- 目录不在会被清理或自动同步的临时位置。
- 没有另一个启动器或游戏进程同时修改文件。

检测完成不代表所有文件都已通过完整校验。首次接管来源不明或曾手动修改的目录时，应再运行校验。

## 安装、更新与预下载

安装和更新按后端返回的游戏构建执行。可用操作取决于当前版本：

- **安装**：下载完整资源并写入新目录。
- **更新**：选择匹配的补丁或远程资源，将本地版本更新到目标版本。
- **预下载**：提前取得下一版本资源，等待版本开放后应用。
- **暂停与继续**：对支持的下载阶段保留任务状态并恢复。

任务进行中不要移动游戏目录、删除暂存文件或同时运行其他修复工具。失败后优先使用页面提供的重试或恢复操作。

## 校验与修复

完整性校验会根据资源索引识别缺失或不匹配的文件。修复只针对确认异常的受管资源，不应清理用户无关文件。

::: info 兼容文件保护
`mhypbase.dll` 由启动器管理。普通更新、修复、校验和清理必须忽略它；如果其内容被修改，启动器会恢复固定的兼容版本。
:::

校验前请关闭游戏。若校验结果反复变化，检查磁盘状态、目录权限、安全软件和其他同步程序。

## 游戏运行组件

MHGLauncher 使用从固定源码构建的 Wine 11.0 与 DXMT 图形转换层，并通过校验清单安装运行组件。它不依赖 CrossOver.app，也不包含 CrossOver 图形界面或专有应用代码。

运行组件与游戏文件分开存放。重新安装 App 不一定会删除已下载的游戏运行环境；清理前确认目标目录，避免误删游戏资源。

## 性能模式

启动前可以选择应用提供的性能配置，例如 MSync 或 ESync。不同系统版本、游戏版本和设备配置的表现可能不同，不存在对所有设备都最优的固定选项。

出现启动失败、卡死或异常退出时：

1. 恢复默认或此前可用的性能模式。
2. 确认运行组件校验通过。
3. 检查游戏是否仍有未完成的更新任务。
4. 参考[故障排查](./troubleshooting)收集非敏感信息。

## 启动与退出

游戏启动通过类型化的 launch session 执行。启动器可能临时调整游戏文件、环境或配置，并在游戏进程退出、启动失败或取消后恢复这些改动。

游戏运行时不要强制结束本地后端。正常关闭游戏后等待启动器更新状态；如果恢复过程失败，先不要再次启动游戏，以免覆盖现场。
