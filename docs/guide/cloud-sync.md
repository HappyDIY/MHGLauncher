# 云同步

云同步是可选功能。不开启云端也可以安装、运行游戏并使用本地旅行数据。

## 同步内容

当前云端围绕游戏 UID 保存：

- 祈愿历史。
- 成就进度。

账号 Cookie、刷新令牌和其他米游社凭据不属于云同步数据，不应上传到云服务数据库。

## 登录与 UID

应用连接配置好的云服务后，会建立独立的云端会话。云端登录与米游社登录是两套不同流程：

- 米游社登录用于访问游戏角色与官方数据。
- 云端登录用于访问自托管或项目提供的数据存储。

每次上传或恢复前检查当前 UID，尤其是在应用中保存了多个游戏身份时。

## 上传与恢复

“上传”把当前本地数据发送到云端；“恢复”从云端读取数据并写入本地。执行前先回答两个问题：

1. 当前页面显示的 UID 是否正确？
2. 哪一侧的数据更新、更完整？

::: warning 恢复不是自动冲突合并
当本地和云端都发生过修改时，不要把“恢复”当作无损合并。先导出或备份本地数据，再执行可能覆盖内容的操作。
:::

## 更换云服务

云服务地址在构建 App 时从根目录 `.env` 写入应用配置：

```dotenv
MHG_CLOUD_BASE_URL=https://cloud.example.com
```

修改 `.env` 后需要重新构建 App。不要把服务令牌或管理后台密钥写进客户端配置。

自建服务的部署与密钥要求参见[自托管云服务](../operations/self-hosting)。

## 同步失败

按以下顺序检查：

1. 当前 Mac 能否访问已配置的 HTTPS 地址。
2. 云端和数据库健康检查是否正常。
3. 云端会话是否已过期。
4. 当前 UID 是否存在对应数据。
5. 服务端日志中是否只有非敏感错误信息。

不要通过关闭 TLS 校验或把管理令牌放进客户端来绕过连接问题。
