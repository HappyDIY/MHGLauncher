# 旅行数据

MHGLauncher 把祈愿记录、实时便笺、角色、成就和消息提醒放在同一个本地应用中。这些数据与当前选择的游戏 UID 关联。

## 祈愿记录

“祈愿记录”页面可同步并查看：

- 各卡池的历史记录和统计。
- 当前保底进度与五星时间线。
- 角色活动、武器活动等历史卡池。
- 抽卡 URL 导入。
- UIGF 文件导入和导出。

同步或导入前确认当前 UID。导入文件可能包含多个 UID；不要把其他账号的数据误合并到当前身份。

## UIGF 导入与导出

UIGF 用于在兼容工具之间交换祈愿历史。

- 导入前保留原始文件副本。
- 导出后检查文件中的 UID 和时间范围。
- 不要手工修改 JSON 字段来“修复”记录。
- 不要把包含个人 UID 的文件公开上传。

清空祈愿记录属于破坏性操作。执行前先导出备份，并确认云端是否仍保存了旧副本。

## 实时便笺

“实时便笺”显示树脂、洞天宝钱、探索派遣等状态。数据来自当前 Provider 对应的官方服务接口，刷新可能受登录状态、网络和接口频率限制。

旧数据仍可用于查看时，刷新失败不会必然清空页面。请根据页面的更新时间判断内容是否新鲜。

## 我的角色

角色页面展示等级、命座、武器、圣遗物与详细属性。图片等资源可能由本地缓存提供，首次载入或刷新后需要等待资源准备完成。

角色资料是查询结果，不会修改游戏内角色配置。

## 成就管理

成就页面支持搜索、筛选和维护完成进度。成就数据默认保存在本地，可按需上传或从配置的云端恢复。

恢复云端成就前，先确认目标 UID 和操作方向。若本地与云端都有修改，当前版本不会替你判断哪一份更重要。

## 消息提醒

提醒用于关注资源恢复和版本动态。macOS 通知权限由系统控制；应用内开关打开但系统权限关闭时，通知仍不会出现。

前往“系统设置 → 通知 → MHGLauncher”检查系统授权，并确保应用内相应提醒已启用。
