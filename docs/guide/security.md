# 隐私与风险

MHGLauncher 是《原神》国服的非官方第三方启动器，与米哈游、HoYoverse 及其关联方无隶属、授权或合作关系。

## 账号与兼容层风险

通过 Wine 和 DXMT 等兼容组件运行游戏，可能违反游戏服务条款或触发账号处罚，也可能出现数据损坏、性能下降、更新失败和无法启动等问题。

项目无法对适用性、稳定性、安全性或使用后果作出保证。是否使用以及使用哪个账号，应由用户自行判断。

## 凭据处理

账号 Cookie、刷新令牌和其他敏感凭据应保存在 macOS Keychain：

- 不写入 SQLite 或 UserDefaults。
- 不进入 fixture、测试快照或契约语料。
- 不出现在日志、崩溃报告和分析数据中。
- 不上传到云同步数据库。

遇到问题时，只提供经过脱敏的错误码、阶段和版本信息。

## 本地通信

SwiftUI 前端与本地后端通过每次启动独立创建的 Unix Domain Socket 通信：

- Socket 文件权限为 `0600`。
- 每次运行使用随机 Bearer Token。
- 所有 API 路由都要求鉴权。
- 后端检测父进程消失后自行退出。

不要把本地后端改为 TCP 监听，也不要复用或记录运行令牌。

## 文件操作

安装、更新和修复游戏前：

1. 备份重要游戏文件和用户数据。
2. 确认目标目录与可用磁盘空间。
3. 关闭游戏和其他启动器。
4. 不要在任务进行中移动或同步目录。

启动器会尽力在游戏退出、启动失败或取消后恢复临时修改，但异常断电、磁盘错误和外部程序并发写入仍可能阻止恢复。

## 开源运行组件

项目只应获取可审计的开源 Wine、DXMT 和 HDiffPatch 组件，并固定来源、版本、许可证和 SHA-256。第三方许可与来源记录见仓库中的 [GAME_RUNTIME_NOTICES.md](https://github.com/HappyDIY/MHGLauncher/blob/main/packaging/GAME_RUNTIME_NOTICES.md)。

仓库当前没有根级开源许可证。在许可证明确前，不要将项目源码视为已经获得复制、修改或再分发授权。
