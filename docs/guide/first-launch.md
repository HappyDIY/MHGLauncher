# 首次启动与账号

MHGLauncher 的本地后端随 App 一起启动，通过每次运行生成的 Unix Domain Socket 与前端通信。用户不需要单独启动后端，也不应把它改成 TCP 服务。

## 首次启动流程

1. 阅读并确认应用内风险说明。
2. 等待本地后端和基础资源就绪。
3. 添加米游社账号。
4. 从账号下的角色列表中选择当前《原神》国服身份。
5. 定位已有游戏目录，或开始新的游戏安装。
6. 在首次启动游戏前安装经过校验的运行组件。

如果启动过程停在后端或资源准备阶段，先查看[故障排查](./troubleshooting)，不要反复删除应用数据。

## 登录方式

当前版本支持三类登录流程：

| 方式 | 适用场景 |
| --- | --- |
| 米游社扫码 | 在移动端确认登录，避免手动输入凭据 |
| 手机验证码 | 使用手机号获取并提交验证码 |
| Cookie | 已了解凭据含义并需要手动导入时使用 |

登录成功后，应用会读取账号可用的游戏角色。一个米游社账号可能对应多个游戏身份，需要明确选择当前角色。

::: danger 不要泄露凭据
Cookie、刷新令牌、短信验证码、二维码登录结果和云端会话令牌都属于敏感信息。不要将它们粘贴到 Issue、聊天记录、截图、终端历史或测试输出中。
:::

## 凭据保存位置

账号凭据保存在 macOS Keychain，不写入 SQLite、UserDefaults、fixture、快照或普通日志。本地数据库保存业务数据和非秘密状态，但不应成为凭据备份来源。

移除账号时，应通过应用内账号管理完成。不要通过直接编辑数据库来切换或删除账号。

## 切换游戏身份

在“账号”页面选择另一个角色后，与 UID 关联的祈愿、角色、成就和云同步操作也会切换到对应身份。执行导入、覆盖或恢复前，先确认页面显示的 UID。

账号登录只负责获取当前会话和角色身份，不等于启用云同步。云端功能需要另行登录，参见[云同步](./cloud-sync)。

## 下一步

- 已有游戏文件：前往[游戏管理](./game-management)定位并校验目录。
- 需要新安装：在“游戏”页面选择目标目录并启动安装任务。
- 只想查看玩家资料：先确保当前角色正确，再打开“实时便笺”或“我的角色”。
