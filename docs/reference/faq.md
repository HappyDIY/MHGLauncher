# 常见问题

## 需要购买或安装 CrossOver 吗？

不需要。MHGLauncher 使用开源 Wine 与 DXMT 运行组件，不依赖 CrossOver.app 或其专有应用代码。

## 已有游戏文件还要重新下载吗？

不一定。可以先让启动器检测已有游戏目录，再按校验结果补全或修复资源。来源不明或曾手动修改的目录建议执行完整校验。

## 支持 Intel Mac 吗？

不支持。当前 Swift 包和打包流程只面向 Apple 芯片 arm64。

## 支持国际服或其他游戏吗？

不支持。当前产品范围仅包括《原神》国服。

## 支持 macOS 15 或更早版本吗？

不支持。当前最低目标是 macOS 26。

## 为什么需要从源码构建？

项目仍处于开发预览阶段，暂无经过公证的 DMG 或正式发行包。发布构建还要求项目统一签名证书及私钥，因此未获授权的普通用户当前可能无法完成构建。

## 账号凭据会上传到云端吗？

不会作为云同步数据上传。敏感凭据应留在 macOS Keychain；云端只处理对应 UID 的祈愿和成就数据。

## 不配置云端还能使用吗？

可以。游戏管理和本地旅行数据功能不依赖云同步。

## 云端恢复会自动合并冲突吗？

不要这样假设。本地与云端都发生变化时，先备份本地数据并确认操作方向，再上传或恢复。

## 普通更新会替换 `mhypbase.dll` 吗？

普通更新、修复、校验和清理应忽略这个由启动器管理的文件。如果它被修改，启动器恢复固定兼容版本。

## 在哪里报告问题？

前往 [GitHub Issues](https://github.com/HappyDIY/MHGLauncher/issues)。提交前按[故障排查](../guide/troubleshooting)整理经过脱敏的信息。
